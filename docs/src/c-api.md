# C API reference

`libfsspec` is the shared library that contains the process-wide filesystem registry and
the built-in backends. Its interface is `fsspec.h`. The `fsspec_sys` crate declares the
same interface for Rust.

## Files

| Item      | Wheel location                                                  |
| --------- | --------------------------------------------------------------- |
| Header    | `fsspec_rs/include/fsspec/fsspec.h`                             |
| Library   | `fsspec_rs/lib/libfsspec.so`, `libfsspec.dylib`, `fsspec.dll`   |
| Link name | `fsspec`                                                        |
| Symbols   | every exported function and type starts with `fsspec_`          |
| Source    | `rust/capi` (`fsspec_capi` crate), header generated by cbindgen |

`fsspec_rs` reports these paths at runtime:

| Function                       | Returns                                          |
| ------------------------------ | ------------------------------------------------ |
| `fsspec_rs.get_prefix()`       | the package directory                            |
| `fsspec_rs.get_include()`      | the directory containing `fsspec/fsspec.h`       |
| `fsspec_rs.get_library_dirs()` | a list with the directory containing the library |
| `fsspec_rs.get_libraries()`    | `["fsspec"]`                                     |

The extension module adds two functions:

| Function                                    | Returns                                                               |
| ------------------------------------------- | --------------------------------------------------------------------- |
| `fsspec_rs.fsspec_rs.linked_to_libfsspec()` | `True` when the extension uses `libfsspec`; `False` in Pyodide builds |
| `fsspec_rs.fsspec_rs.protocols()`           | the protocols registered in the registry the extension uses, sorted   |

## ABI version

`FSSPEC_ABI_VERSION` is the version the header describes; `fsspec_abi_version()` returns
the version the loaded library was built with. Both are `1`. Every vtable and factory
struct starts with `struct_size` and `abi_version`. Registration fails with
`FSSPEC_INVALID_ARGUMENT` when `abi_version` differs from the library's, or when
`struct_size` is smaller than those two fields or larger than 64 KiB. A struct shorter
than the library's is accepted; the missing trailing fields are treated as null.

## Status codes

Every fallible function returns `fsspec_status`, an `int32_t`:

| Code                       | Value | Rust `FsError`     |
| -------------------------- | ----- | ------------------ |
| `FSSPEC_OK`                | 0     |                    |
| `FSSPEC_NOT_FOUND`         | 1     | `NotFound`         |
| `FSSPEC_PERMISSION_DENIED` | 2     | `PermissionDenied` |
| `FSSPEC_ALREADY_EXISTS`    | 3     | `AlreadyExists`    |
| `FSSPEC_NOT_A_DIRECTORY`   | 4     | `NotADirectory`    |
| `FSSPEC_IS_A_DIRECTORY`    | 5     | `IsADirectory`     |
| `FSSPEC_IO`                | 6     | `IoError`          |
| `FSSPEC_INVALID_ARGUMENT`  | 7     | `InvalidArgument`  |
| `FSSPEC_NOT_SUPPORTED`     | 8     | `NotSupported`     |
| `FSSPEC_OTHER`             | 9     | `Other`            |

| Function                              | Description                                                                                               |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `fsspec_last_error_message()`         | Message for the last failure on the calling thread, or null. Valid until the next failure on that thread. |
| `fsspec_set_last_error(message, len)` | Sets the thread's message. Foreign backends call it before returning a failing status.                    |
| `fsspec_clear_last_error()`           | Clears the thread's message.                                                                              |

Panics inside `libfsspec` are caught at the boundary and returned as `FSSPEC_OTHER`.

## Strings and memory

Arguments are UTF-8 pointer and length pairs and need no NUL terminator. Values that
`libfsspec` returns are owned by the caller and freed with the matching function:

| Type                    | Fields                                                            | Free with                    |
| ----------------------- | ----------------------------------------------------------------- | ---------------------------- |
| `fsspec_string`         | `data` (NUL-terminated), `len` (without the NUL)                  | `fsspec_string_free`         |
| `fsspec_string_list`    | `items`, `len`                                                    | `fsspec_string_list_free`    |
| `fsspec_bytes`          | `data`, `len`                                                     | `fsspec_bytes_free`          |
| `fsspec_file_info`      | `name`, `size`, `file_type`, `created_ns`, `modified_ns`, `extra` | `fsspec_file_info_free`      |
| `fsspec_file_info_list` | `items`, `len`                                                    | `fsspec_file_info_list_free` |

`created_ns` and `modified_ns` are nanoseconds since the Unix epoch, or `-1` when
unknown. `file_type` is `FSSPEC_FILE_TYPE_FILE`, `FSSPEC_FILE_TYPE_DIRECTORY`, or
`FSSPEC_FILE_TYPE_OTHER`. `extra` contains backend-specific fields as alternating key and
value strings.

All of these buffers use the platform allocator: `malloc` on Unix and
`HeapAlloc(GetProcessHeap(), ...)` on Windows. Foreign backends allocate the values
they return through vtable callbacks the same way, and `libfsspec` frees them.

## Options

`fsspec_options` is a string-to-string map.

| Function                                                      | Description                                       |
| ------------------------------------------------------------- | ------------------------------------------------- |
| `fsspec_options_new()`                                        | Creates an empty map.                             |
| `fsspec_options_set(options, key, key_len, value, value_len)` | Sets a key, replacing an earlier value.           |
| `fsspec_options_items(options, out)`                          | Alternating key and value strings, sorted by key. |
| `fsspec_options_free(options)`                                | Frees the map. Null is ignored.                   |

A null `fsspec_options *` argument means no options.

## Registry

| Function                                                      | Description                                                                                                    |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `fsspec_url_to_fs(url, url_len, options, out_fs, out_path)`   | Resolves a URL through the registry. `out_path`, when not null, receives the path to use with the filesystem.  |
| `fsspec_register_filesystem(protocol, protocol_len, factory)` | Registers a factory, replacing an earlier one and dropping its cached instances. The factory struct is copied. |
| `fsspec_protocols(out)`                                       | Registered protocols, sorted.                                                                                  |
| `fsspec_register_fallback(factory)`                           | Installs the factory used for protocols nothing registered; null clears it. It is given the whole URL.         |

URL resolution, caching, and the built-in protocols (`file`, `local`, `memory`, `s3`) and their
options are the same as the Rust registry; see
"Filesystem registry" in the [Rust reference](rust.md).

`fsspec_fs_factory`:

| Field            | Description                                                                                    |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| `struct_size`    | `sizeof(fsspec_fs_factory)`                                                                    |
| `abi_version`    | `FSSPEC_ABI_VERSION`                                                                           |
| `data`           | Passed to every callback.                                                                      |
| `create`         | Required. Builds a filesystem for a path and options; returns it in `out`.                     |
| `instance_scope` | Optional. Returns the part of the path that needs its own instance, such as a bucket.          |
| `release`        | Optional. Called with `data` when the registry drops the factory, such as when it is replaced. |

## Filesystems

`fsspec_fs *` is a reference-counted handle.

| Function                                                              | Description                                                                                                                                                                  |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fsspec_fs_retain(fs)`                                                | Another handle to the same filesystem.                                                                                                                                       |
| `fsspec_fs_release(fs)`                                               | Frees a handle; the filesystem is dropped with its last handle.                                                                                                              |
| `fsspec_fs_protocols(fs, out)`                                        | Protocol names of the filesystem.                                                                                                                                            |
| `fsspec_fs_root_marker(fs, out)`, `fsspec_fs_sep(fs, out)`            | Root marker and path separator.                                                                                                                                              |
| `fsspec_fs_strip_protocol(fs, path, path_len, out)`                   | The path without its protocol prefix, as the backend normalises it; an empty result is the root marker.                                                                      |
| `fsspec_fs_unstrip_protocol(fs, path, path_len, out)`                 | The path with the backend's protocol prefix.                                                                                                                                 |
| `fsspec_fs_ls(fs, path, path_len, detail, out)`                       | Lists a directory. With `detail` false, entries may contain only names.                                                                                                      |
| `fsspec_fs_info(fs, path, path_len, out)`                             | Metadata for one path.                                                                                                                                                       |
| `fsspec_fs_exists(fs, path, path_len, out)`                           | Whether a path exists.                                                                                                                                                       |
| `fsspec_fs_cat_file(fs, path, path_len, start, end, out)`             | Reads a file, or `[*start, *end)` when the pointers are not null. Negative offsets count from the end.                                                                       |
| `fsspec_fs_pipe_file(fs, path, path_len, data, data_len)`             | Writes a file, replacing it.                                                                                                                                                 |
| `fsspec_fs_rm_file(fs, path, path_len)`                               | Deletes one file.                                                                                                                                                            |
| `fsspec_fs_cp_file(fs, src, src_len, dst, dst_len)`                   | Copies one file within the filesystem.                                                                                                                                       |
| `fsspec_fs_mkdir(fs, path, path_len, create_parents)`                 | Creates a directory.                                                                                                                                                         |
| `fsspec_fs_rmdir(fs, path, path_len)`                                 | Removes an empty directory.                                                                                                                                                  |
| `fsspec_fs_open(fs, path, path_len, mode, mode_len, out)`             | Opens a file with mode `rb`, `wb`, `ab`, or `xb`.                                                                                                                            |
| `fsspec_fs_open_ex(fs, path, path_len, mode, mode_len, options, out)` | As `fsspec_fs_open`, with open options `block_size`, `max_blocks`, `autocommit`, and `cache_type` (`none`, `readahead`, `block`, `all`). Vtable backends receive no options. |

## Files

`fsspec_file *` is an open file, closed with `fsspec_file_close`.

| Function                                                | Description                                                                                   |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `fsspec_file_read(file, buf, len, out_read)`            | Reads up to `len` bytes; `*out_read` is zero at end of file.                                  |
| `fsspec_file_write(file, data, len, out_written)`       | Writes bytes; `out_written` may be null.                                                      |
| `fsspec_file_seek(file, offset, whence, out_position)`  | `whence` is 0 (start), 1 (current), or 2 (end).                                               |
| `fsspec_file_tell(file, out_position)`                  | Current offset.                                                                               |
| `fsspec_file_flush(file)`                               | Flushes buffered writes.                                                                      |
| `fsspec_file_size(file, out_size)`                      | Size, or `-1` when unknown.                                                                   |
| `fsspec_file_get_info(file, out)`                       | Metadata for the open file.                                                                   |
| `fsspec_file_commit(file)`, `fsspec_file_discard(file)` | Commits or discards a transactional write.                                                    |
| `fsspec_file_close(file)`                               | Flushes and frees the handle. The handle is freed even when the flush fails. Null is ignored. |

## Foreign backends

`fsspec_fs_from_vtable(vtable, data)` wraps an implementation written outside
`libfsspec` as an `fsspec_fs *`, and `fsspec_file_from_vtable(vtable, data)` does the
same for an open file. Both copy the vtable, pass `data` to every callback, and return
null with the error message set on failure.

`fsspec_fs_vtable`:

| Field                                                         | Description                                                                                                                                                                |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `struct_size`, `abi_version`                                  | As for factories.                                                                                                                                                          |
| `protocol`                                                    | NUL-terminated, comma-separated protocol names, such as `"file,local"`.                                                                                                    |
| `root_marker`, `sep`                                          | NUL-terminated strings; null uses the defaults.                                                                                                                            |
| `ls`, `info`, `rm_file`, `cp_file`, `mkdir`, `rmdir`, `open`  | The `FileSystem` primitives. A null callback makes its operation return `FSSPEC_NOT_SUPPORTED`. Other operations, such as `cat_file` and `exists`, are derived from these. |
| `release`                                                     | Called with `data` when the last handle is released.                                                                                                                       |
| `strip_protocol`, `unstrip_protocol`, `cat_file`, `pipe_file` | Optional, after `release`. A backend that overrides these in Rust keeps its own behaviour across the ABI; null uses the derived defaults.                                  |

`fsspec_file_vtable` has `read`, `write`, `seek`, `flush`, `size`, `info`, `commit`,
`discard`, and `release`. A null `read`, `write`, `seek`, or `info` returns
`FSSPEC_NOT_SUPPORTED`; a null `size` reports `-1`; a null `flush`, `commit`, or
`discard` succeeds without doing anything. `release` is called on close.

## Rust bindings

The `fsspec_sys` crate declares the C functions without a `#[link]` attribute; the
build links `libfsspec` (hatch-rs `links`) or compiles `fsspec_capi` in. It contains no
registry state.

| Item                                                           | Description                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `url_to_fs(url, &FsOptions)`                                   | Resolves a URL through `libfsspec`; returns a `SharedFileSystem` and the path. |
| `register_filesystem(protocol, factory)`                       | Registers a `FilesystemFactory` in `libfsspec`.                                |
| `register_fallback(factory)`                                   | Installs or clears the factory for protocols nothing registered.               |
| `use_shared_registry()`                                        | Routes `fsspec_rs::url_to_fs` and `register_filesystem` through `libfsspec`.   |
| `protocols()`                                                  | Registered protocols, sorted.                                                  |
| `abi_version()`                                                | ABI version of the loaded library.                                             |
| `ForeignFileSystem`, `ForeignFile`                             | `FileSystem` and `FsFile` implementations over `libfsspec` handles.            |
| `export_filesystem(fs)`, `export_file(file)`                   | Wrap Rust implementations as `fsspec_fs *` and `fsspec_file *`.                |
| `status_code`, `error_from_status`, `check`, `take_last_error` | Conversions between `FsError` and status codes.                                |
| `ffi`, `types`                                                 | Raw declarations and `repr(C)` types of `fsspec.h`.                            |
